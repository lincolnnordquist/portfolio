# Lincoln's Personal Site

Personal portfolio, blog, and games site built with Next.js. See `CLAUDE.md`
for the architecture and design intent (two-mode structure, per-fandom
theming, blog/games plans).

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Other commands

```bash
npm run build   # production build
npm run start   # run the production build
npm run lint    # lint
```
